# Credit Card Payment System

## Project Overview

A full-stack Credit Card Payment System built using React, Django REST Framework, FastAPI, MySQL, Tailwind CSS, and Docker.

The application allows users to register, log in, manage cards, make simulated payments, and view transaction history.

## Features

- User registration and login
- JWT authentication
- Protected routes
- Credit and debit card management
- Card masking
- Payment processing
- Transaction history
- Transaction filtering
- Admin dashboard
- Django admin panel
- MySQL database
- REST APIs
- FastAPI payment API
- Docker containerization
- Postman API testing
